    AUDIOLIB_sinusoidGenerator¶

    group AUDIOLIB_sinusoidGenerator

    Kernel for generating a sine wave with smooth frequency transitions.

    This kernel generates an output signal \(y[n]\) by calculating the sine of a phase \(\phi[n]\):

    \[ y[n] = \sin(\phi[n]) \]

    The phase \(\phi[n]\) is accumulated at each sample by a phase increment value, \(\Delta\phi[n]\), which determines the instantaneous frequency \(f[n]\). The phase wraps around \(2\pi\) to remain in range.

    \[ \phi[n] = (\phi[n-1] + \Delta\phi[n]) \pmod{2\pi} \]

    The phase increment \(\Delta\phi[n]\) is calculated from the frequency \(f[n]\) and the sampling rate \(f_s\):

    \[ \Delta\phi[n] = \frac{2 \pi f[n]}{f_s} \]

    The kernel supports smooth transitions between a startFrequency and a targetFrequency over a specified smoothingTime.

    1. Instant Frequency Change (smoothingTime = 0)

    The phase increment \(\Delta\phi[n]\) is immediately set to the target value derived from targetFrequency ( \(f_{\text{target}}\)).

    \[ \Delta\phi[n] = \Delta\phi_{\text{target}} = \frac{2 \pi f_{\text{target}}}{f_s} \]

    2. Smooth Frequency Change (smoothingTime > 0)

    The phase increment \(\Delta\phi[n]\) is updated using a first-order low-pass filter, allowing it to smoothly approach the target phase increment \(\Delta\phi_{\text{target}}\).

    \[ \Delta\phi[n] = \alpha \cdot \Delta\phi[n-1] + (1 - \alpha) \cdot \Delta\phi_{\text{target}} \]

    The smoothing coefficient, \(\alpha\), is derived from the smoothingTime ( \(T_{\text{smooth}}\) in milliseconds, acting as the time constant \(\tau\)) and the sampling rate \(f_s\):

    \[ \alpha = e^{\frac{-1}{f_s \cdot (T_{\text{smooth}} / 1000)}} \]

    The initial phase \(\phi[0]\) is set via startPhase (in degrees), which is converted to radians:

    \[ \phi[0] = \frac{\text{startPhase} \cdot \pi}{180.0} \]

    struct AUDIOLIB_sinusoidGenerator_SetArgs¶
    #include <AUDIOLIB_sinusoidGenerator.h>

    Runtime-settable parameters for configuring the Sinusoid Generator.

    This structure is used with AUDIOLIB_sinusoidGenerator_set to control the generator’s behavior dynamically.

    Public Members¶

    float startFrequency¶

    The frequency of the signal at the start (in Hz).

    float targetFrequency¶

    The target frequency for the signal to transition to (in Hz).

    float startPhase¶

    The phase at which the signal starts (in degrees).

    float smoothingTime¶

    The time to transition from start to target frequency (in milliseconds). 0 for instant change.
