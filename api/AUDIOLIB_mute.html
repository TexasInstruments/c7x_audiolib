    AUDIOLIB_mute¶

    group AUDIOLIB_mute

    A kernel for applying multichannel audio muting with various fade options.

    This kernel mutes or unmutes an audio signal by applying a gain factor, \(G[n]\), which transitions between 1.0 (unmuted) and 0.0 (muted). To avoid audible clicks, the transition can be smoothed over a specified fadeTime. The kernel supports three distinct fade behaviors.

    1. Hard Mute (fadeType = 2 or fadeTime = 0)

    The gain changes instantly to its target value.

    \[ G[n] = G_{\text{target}} \]
    where \(G_{\text{target}}\) is either 0.0 or 1.0.

    2. Linear Fade (fadeType = 0)

    The gain changes linearly at a constant rate over the specified fadeTime. The per-sample gain step, \(G_{\text{step}}\), is calculated based on the total number of samples in the fade duration:

    \[ G_{\text{step}} = \frac{G_{\text{target}} - G_{\text{current}}}{ (T_{\text{fade}} / 1000) \cdot f_s } \]
    The gain at each sample, \(G[n]\), is then updated as:
    \[ G[n] = G[n-1] + G_{\text{step}} \]
    where \(T_{\text{fade}}\) is the fade time in milliseconds and \(f_s\) is the sampling rate.

    3. Smooth Fade (fadeType = 1)

    The gain follows an exponential curve, which provides a more natural-sounding fade. This is implemented using a first-order low-pass filter where the gain smoothly approaches the target. The update equation is:

    \[ G[n] = \alpha \cdot G[n-1] + (1 - \alpha) \cdot G_{\text{target}} \]
    The smoothing coefficient, \(\alpha\), is derived from the fadeTime (acting as the time constant \(\tau\)) and the sampling rate \(f_s\):
    \[ \alpha = e^{\frac{-1}{f_s \cdot (\text{T}_{\text{fade}} / 1000)}} \]

    The final output signal, \(y[n]\), is computed by applying the current gain \(G[n]\) to the input signal, \(x[n]\):

    \[ y[n] = x[n] \cdot G[n] \]

    AUDIOLIB_STATUS AUDIOLIB_mute_set(AUDIOLIB_kernelHandle handle, AUDIOLIB_mute_SetArgs *pKerSetArgs)¶

    Sets the runtime parameters for the Mute kernel.

    This function updates the internal state of the kernel based on the provided settings. It calculates the necessary gain coefficients for the selected fade type. For a detailed explanation of the formulas used, please see the AUDIOLIB_mute group description.

    Parameters:¶
    AUDIOLIB_kernelHandle handle¶

    [in] A valid handle to the kernel instance.

    AUDIOLIB_mute_SetArgs *pKerSetArgs¶

    [in] Pointer to the structure containing the desired mute parameters.

    Returns:¶

    Status code indicating success or failure. See AUDIOLIB_STATUS.

    Please refer to details under AUDIOLIB_mute_exec

    struct AUDIOLIB_mute_InitArgs¶
    #include <AUDIOLIB_mute.h>

    Initialization parameters for the Mute kernel.

    These parameters are set once when the kernel is initialized.

    Public Members¶

    int8_t funcStyle¶

    The implementation style to use. See AUDIOLIB_FUNCTION_STYLE for options.

    int32_t samplingRate¶

    The audio sampling rate in Hz (e.g., 48000).

    uint8_t isInterleaved¶

    Specifies the data format: 1 for interleaved, 0 for non-interleaved (planar).

    struct AUDIOLIB_mute_SetArgs¶
    #include <AUDIOLIB_mute.h>

    Runtime-settable parameters for configuring the Mute kernel.

    This structure is used with AUDIOLIB_mute_set() to control the muting behavior dynamically.

    Public Members¶

    uint32_t isMute¶

    Control switch for muting: 1 to engage mute (fade-out), 0 to disengage (fade-in).

    float fadeTime¶

    The duration of the fade-in or fade-out ramp in milliseconds. A value of 0 results in a hard (instant) mute.

    uint32_t fadeType¶

    The type of fade curve to apply. See fadeType for options.
