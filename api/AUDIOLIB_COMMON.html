    Common definitions¶

    group Common definitions

    This module consists of definitions (macros, structures, utility functions) that are commonly applicable to all AUDIOLIB kernels.

    Defines¶

    AUDIOLIB_PARAM_SIZE¶

    Parameter structure size in bytes.

    AUDIOLIB_ALIGN_SHIFT_64BYTES¶

    Number of bits to shift for 64-byte memory alignment.

    AUDIOLIB_ALIGN_SHIFT_128BYTES¶

    Number of bits to shift for 128-byte memory alignment.

    AUDIOLIB_ALIGN_SHIFT_256BYTES¶

    Number of bits to shift for 256-byte memory alignment.

    AUDIOLIB_ALIGN_64BYTES¶

    Align by 64-byte memory alignment.

    AUDIOLIB_ALIGN_128BYTES¶

    Align by 128-byte memory alignment.

    AUDIOLIB_ALIGN_256BYTES¶

    Align by 256-byte memory alignment.

    AUDIOLIB_L2DATA_ALIGN_SHIFT¶

    Set the default L2 data alignment.

    AUDIOLIB_L2DATA_ALIGNMENT¶

    Macro that specifies the alignment of data buffers in L2 memory for optimal performance.

    Typedefs¶

    typedef double AUDIOLIB_D64¶

    Double precision floating point.

    typedef float AUDIOLIB_F32¶

    Single precision floating point.

    typedef AUDIOLIB_STATUS_NAME AUDIOLIB_STATUS¶

    Return value for AUDIOLIB functions.

    typedef void *AUDIOLIB_kernelHandle¶

    Handle type for AUDIOLIB operations.

    Enums¶

    enum AUDIOLIB_STATUS_NAME¶

    The enumeration of all status codes.

    Values:

    enumerator AUDIOLIB_SUCCESS¶

    0 => No error

    enumerator AUDIOLIB_ERR_FAILURE¶

    1 => Unspecified error

    enumerator AUDIOLIB_ERR_INVALID_VALUE¶

    2 => Invalid parameter value

    enumerator AUDIOLIB_ERR_INVALID_TYPE¶

    3 => Invalid parameter type (AUDIOLIB_data_type_e data_type)

    enumerator AUDIOLIB_ERR_INVALID_DIMENSION¶

    4 => Dimension parameter (width/height) is too big/small

    enumerator AUDIOLIB_ERR_NULL_POINTER¶

    5 => Unsupported null pointer condition

    enumerator AUDIOLIB_ERR_NOT_IMPLEMENTED¶

    6 => Parameter configuration is not supported/implemented

    enumerator AUDIOLIB_ERR_NOT_EQUAL_WIDTH_STRIDE¶

    7 => Stride should be equal to width * element size

    enumerator AUDIOLIB_ERR_NOT_ALIGNED_PTRS_STRIDES¶

    8 => Pointers and stride values are not aligned to documented value

    enumerator AUDIOLIB_ERR_NOT_ALIGNED_WIDTHS¶

    9 => Width values are not aligned to documented value

    enumerator AUDIOLIB_ERR_BUFFER_TOO_SMALL¶

    10 => Buffer size not large enough

    enumerator AUDIOLIB_ERR_INVALID_ACTIVATION¶

    11 => Activation selection incompatible with data type

    enumerator AUDIOLIB_ERR_INVALID_SHIFT¶

    12 => Requested shift amount is not valid

    enumerator AUDIOLIB_ERROR_MAX¶
    enumerator AUDIOLIB_ERR_INVALID_MMA_FLAG¶

    14 => enableMMA flag value in init args not valid

    enum AUDIOLIB_FUNCTION_STYLE¶

    Enumeration for the style of function implementation.

    Values:

    enumerator AUDIOLIB_FUNCTION_NATC¶

    Natural C implementation of the function

    enumerator AUDIOLIB_FUNCTION_OPTIMIZED¶

    Optimized C implementation of the function for the MMA + C7x architecture

    enumerator AUDIOLIB_FUNCTION_MAX¶
